# 倍信：局域网聊天的现代化选择，飞秋的完美替代

## 飞秋用久了，你该升级了

每个办公族都经历过这样的场景：办公室里几十个人用飞秋互发消息，界面停留在 2008 年，聊天窗口简陋、没有历史记录、图片发不了、文件进度看不到……明明是每天用得最多的工具，体验却像上个时代的产物。

**倍信（IPMsg Pro）** 就是来解决这个问题的。它和飞秋在同一网络中完全互通——你用倍信，同事继续用飞秋，消息照收照发，谁都不需要换。但你自己享受到的是微信级别的聊天体验。

## 三个理由让你立刻换掉飞秋

### 1. 微信风格的聊天界面

飞秋那个半屏大小的聊天框，每条消息挤在一起，找不到上下文。倍信用的是**三栏布局**——左侧会话列表、中间联系人、右侧聊天面板，和微信一模一样。消息有气泡、有时间戳、有送达确认，不再是一条条裸文本。

### 2. 消息不再丢失

飞秋关了窗口消息就没了，想找上周的聊天内容？不可能。倍信所有消息**自动存入 SQLite 数据库**，随时翻阅历史，还能搜索关键词。再也不用担心错过重要通知。

### 3. 图片和文件，真正好用

飞秋发图片？不支持。飞秋传文件？一个简陋的进度条，传完了也不知道存哪了。倍信：

- **图片发送**：选图→预览确认→对方收到缩略图→点击查看原图
- **文件传输**：确认接收→实时进度条→一键打开文件夹
- **送达回执**：文字消息也有送达确认，不再"发了不知道对方收到没"

## 和飞秋完全互通，无缝切换

这是最重要的一点——**倍信和飞秋在同一局域网中完全互通**：

- 飞秋用户发消息 → 倍信正常收到
- 倍信用户发消息 → 飞秋正常收到
- 飞秋传文件 → 倍信正常接收
- 倍信传文件 → 飞秋正常接收

倍信实现了 IPMsg v3.0 协议，并且针对飞秋的特殊编码和格式差异做了完整适配（GBK/UTF-8 自动转换、扩展协议兼容等）。你今天装上倍信，明天办公室就能正常用，同事完全不需要改任何东西。

## 零安装，复制即用

倍信是一个**单 exe 文件**，不需要安装，不需要管理员权限，不需要注册表写入。复制到任何目录双击就能运行。前端资源全部打包嵌入 exe，没有额外的 DLL 或资源文件夹依赖。

这也意味着你可以把它放在 U 盘里，在任何 Windows 电脑上即时使用。
